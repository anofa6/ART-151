## What is the difference between a Web API and a JavaScript library?
A Web API is used to get data from an external source, while a library is used to solve a certain problem that the user cannot do or is harder to do with Vanilla Javascript. For example, an API could be used to get the current weather, while a library can be used to draw in 3D.

## How does the reading distinguish between a library and a framework?
The Tone.js library makes it easy to create sound, while the Canvas API allows you to draw on the canvas. They differ because one offers a service while the other allows you to do something a lot easier and simpler.
